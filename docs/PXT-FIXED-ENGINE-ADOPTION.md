`79071f69cd6035a820cbdad93da7343d7d501e4d`, the merged SAMD51 storage and
absent-controller performance correction. Qualification is pending; earlier
engine results do not qualify this consumer composition.

negative observation; this adoption adds no ownership enforcement.

## Separate selected storage fixture

`pxt-gc-runtime/zflash-peripherals.yaml` selects only the manual-storage NVMCTRL
and CMCC peripherals. It is installed alongside the consumer-owned
`guest-zflash.rs` observer in an otherwise clean pinned engine checkout. The
engine's default PyBadge descriptor remains unchanged.

The driver/compiler producer and its 16 dependency inputs remain pinned to
runtime `62a3a408`, CODAL core `2ed19d64` and framework `31abf23d`. They build the
same actual include-adapted ZFlash implementation and authored boot caller.
The new observer binds the consumer checkout and engine provenance, retains
the original real-method/IRQ return observations and checks six ordered phases
in fresh step and batched machines, neighboring bytes and refused operations.
Each scheduler profile must also detect omission of actual erase and program
commits through the specific wrong byte after the real driver returns.

Before merge, independently admit the official run/job/step/artifact identities,
tested consumer tree and ordered parents; acquire each successful original
once and audit its source, image, stream, mutation and notice bindings without
producer imports or guest replay. Every enabled final-head check must pass.

## Follow-up boundary

This fixture does not execute RAFFS/settings, qualify a full board, persist
across reset or power loss, or adopt an installed application engine. Actual
RAFFS/settings composition is a separate subsequent source change: first
declare its storage size and persistence boundary, then link the real GC,
roots, hash/configuration/scheduler and filesystem/settings implementations.
It requires its own affected clean guests, specific mutations and original
audits. Preserve the earlier failures and finite DMA limits.
